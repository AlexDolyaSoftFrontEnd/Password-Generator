# 🔐 Password Generator

Генератор паролей, реализованный на **React**.  

## Возможности
- Выбор длины пароля (от 8 до 32 символов)
- Включение заглавных букв, цифр и специальных символов
- Копирование пароля по клику
- Семантическая и доступная HTML-разметка
- Чистый интерфейс в стиле Apple

## Стек технологий
- React
- CSS Modules
- react-helmet-async

## Использование
1. Выберите длину пароля
2. Отметьте необходимые параметры
3. Нажмите **«Згенерувати пароль»**
4. Кликните по сгенерированному паролю, чтобы скопировать его
